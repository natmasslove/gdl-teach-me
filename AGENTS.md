# Суть проекта

Пользователь хочет больше узнать об истории Великого княжества Литовского (ВКЛ). Отправная точка — подаренные игральные карты с персонажами, знаковыми фигурами в истории государства.

## Исходные материалы

В `input_png/` находятся четыре скана: два изображения с картами (`cards_1.png`, `cards_2.png`) и две страницы кратких справок о персонажах (`description_1.png`, `description_2.png`). Сохранять исходные сканы без изменений.

## Подготовка данных

В каталоге `input/` должны быть:

- Два Markdown-файла, соответствующие двум страницам описания. Сохранять белорусский и русский текст, отделяя версии языка и справки о персонажах. Это транскрипция буклета, а не проверенный исторический источник; не исправлять его исторические утверждения незаметно.
- Двенадцать отдельных PNG с полными изображениями игральных карт. Имя файла — имя персонажа на карте, с сохранением белорусского написания.

## Дальнейшая цель

После подготовки данных совместно с пользователем создавать учебные материалы по истории ВКЛ на основе `input/`. Формат и содержание учебных материалов согласовывать на следующем этапе. Отличать сведения из буклета от дополнений и исторической проверки по другим источникам.
